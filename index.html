POSIX shell toolkit

把 Linux 环境
交给脚本。

LinuxApp 是一个面向 Linux 的纯 POSIX sh 脚本集合，提供统一入口、交互式菜单、在线加载、离线校验和可扩展的生命周期模块。

浏览已有应用 ↓ 开源仓库 ↗
01 / 轻量运行无需构建工具。把仓库放到静态服务，即可直接分发脚本。

清晰、可组合、可迁移。

从一个入口开始，把不同发行版和架构的差异留给模块处理，让基础设施保持简单。

01 / ENTRY

一个入口

main.sh 负责菜单、系统信息和模块调度，交互终端中支持单键选择。

02 / LIFECYCLE

完整生命周期

软件模块遵循安装、启动、停止、更新、卸载与状态查询接口。

03 / DELIVERY

静态分发

一键运行命令基于当前站点地址生成，适合托管到 GitHub Pages、Nginx 或对象存储。

一键使用

复制主入口命令到 Linux 终端，从当前静态站点启动 LinuxApp。

apps / loading...命令地址基于当前站点自动生成
