# 演示软件模块开发示例

本文件是一个无副作用的软件模块开发示例。它不属于 `config/modules.list`，不会出现在 LinuxApp 的运行菜单中，也不会被离线模式当作必需脚本检查。

## 使用方式

复制下面的脚本内容到新的模块目录，例如：

```text
modules/software/example/module.sh
```

然后在 `config/modules.list` 中增加一行：

```text
software|example|modules/software/example/module.sh|示例软件
```

软件模块支持以下动作：`install`、`start`、`stop`、`update`、`uninstall`、`status`。

## 示例代码

```sh
#!/bin/sh

module_state_root=${LINUXAPP_STATE_DIR:-${XDG_CACHE_HOME:-${HOME:-.}/.cache}/linuxapp/state}
module_state_file="$module_state_root/software-example.state"
module_version='示例模块'

module_read_state() {
    if [ -r "$module_state_file" ]; then
        sed -n '1p' "$module_state_file"
    else
        printf '%s\n' 'not-installed'
    fi
}

module_write_state() {
    mkdir -p "$module_state_root" 2>/dev/null || return 1
    printf '%s\n' "$1" > "$module_state_file"
}

module_status() {
    module_state=$(module_read_state)
    case "$module_state" in
        running) printf '运行中|%s|示例服务正在运行\n' "$module_version" ;;
        stopped) printf '已停止|%s|示例软件已安装但未运行\n' "$module_version" ;;
        not-installed) printf '未安装|-|尚未安装示例软件\n' ;;
        *) printf '异常|%s|状态文件内容无法识别\n' "$module_version" ;;
    esac
}

module_install() {
    module_state=$(module_read_state)
    if [ "$module_state" = 'not-installed' ]; then
        module_write_state stopped || return 1
    fi
    printf '%s\n' '示例软件已经安装。'
}

module_start() {
    [ "$(module_read_state)" != 'not-installed' ] || {
        printf '%s\n' '示例软件尚未安装。' >&2
        return 1
    }
    module_write_state running || return 1
    printf '%s\n' '示例软件已启动。'
}

module_stop() {
    [ "$(module_read_state)" = 'running' ] || {
        printf '%s\n' '示例软件当前未运行。' >&2
        return 1
    }
    module_write_state stopped || return 1
    printf '%s\n' '示例软件已停止。'
}

module_update() {
    [ "$(module_read_state)" != 'not-installed' ] || {
        printf '%s\n' '示例软件尚未安装。' >&2
        return 1
    }
    printf '%s\n' '示例软件已完成模拟更新。'
}

module_uninstall() {
    if [ -f "$module_state_file" ]; then
        rm -f "$module_state_file" || return 1
    fi
    printf '%s\n' '示例软件已卸载。'
}

trap 'printf "\\n%s\\n" "示例软件任务已被 Ctrl+C 中断。" >&2; exit 130' INT
case "${1:-status}" in
    install) module_install ;;
    start) module_start ;;
    stop) module_stop ;;
    update) module_update ;;
    uninstall) module_uninstall ;;
    status) module_status ;;
    *) printf '%s\n' '未知的软件动作。' >&2; exit 2 ;;
esac

```

## 开发注意事项

- 模块脚本必须使用 POSIX `sh`，不能依赖 Bash 专属语法。
- 状态输出使用 `状态|信息或版本|说明|可选敏感字段` 格式。
- 真实软件模块应自行处理发行版、架构、权限和依赖差异。
- 完成模块后再把它登记到 `config/modules.list`，登记后离线模式会要求脚本存在。
