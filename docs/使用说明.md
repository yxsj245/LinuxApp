# LinuxApp 使用说明

## 运行

在 Linux 终端执行：

```sh
./main.sh
```

主界面上方显示系统基础信息和模块状态，下方为数字功能区。数字键会立即触发，不需要按回车。已安装列表使用普通的 `|` 分隔文本，不显示表格表头，也不显示模块前置字母键。

离线模式：

```sh
./main.sh -offline
```

离线模式启动前会检查 `config/modules.list` 中登记的全部脚本；任意脚本缺失时不会进入菜单。

非交互终端不会启动菜单。自动化场景可以直接调用已注册模块脚本；当前基础版本没有注册实际模块。

```sh
# 具体模块登记到 config/modules.list 后，再按模块文档调用
# sh modules/language/example/module.sh status
```

## 在线加载与缓存

`config/source.sh` 中的 `LINUXAPP_BASE_URL` 用于统一远端基地址，模块相对路径会自动拼接。需要单独地址时，在 `linuxapp_script_override_url` 的 `case` 分支返回完整 URL。

`config/modules.list` 使用四列格式：`类型|模块 ID|相对脚本路径|显示名称`。模块不再配置或依赖英文字母键；进入“应用管理”后，先选择软件模块或语言模块，再按界面显示的数字序号进入具体模块。演示软件和演示语言均已移至 `docs/`，仅作为开发参考，不会出现在运行菜单中。

默认缓存 3600 秒，目录优先使用 `XDG_CACHE_HOME/linuxapp`，否则使用 `~/.cache/linuxapp`。可通过环境变量覆盖：

```sh
LINUXAPP_BASE_URL=https://example.com/linuxapp \
LINUXAPP_CACHE_TTL=3600 \
./main.sh
```

有本地脚本时，远端连接建立超时（默认 10 秒）会显示警告并回退本地脚本；本地脚本不存在时会等待远端结果。下载使用临时文件并原子替换。

## 模块接口

软件模块必须支持：`install`、`start`、`stop`、`update`、`uninstall`、`status`。

语言模块支持：`install`、`uninstall`、`status`。框架会拒绝语言模块的启动、停止和更新动作。

状态命令输出一行管道分隔内容，第四列可选，用于凭证等敏感信息：

```text
状态|信息或版本|说明|可选敏感字段
```

第四列在普通运行中会显示为 `******`，只有在交互式终端同时传入 `--show-secrets` 时才显示明文。敏感值不会写入缓存日志。

## SSH 登录钩子

安装当前用户的登录钩子：

```sh
./main.sh --install-ssh-hook
```

移除钩子：

```sh
./main.sh --remove-ssh-hook
```

钩子写入用户级 `.profile`，只在交互式 SSH 会话中运行，不替换用户 Shell。重复安装不会追加重复片段。

信号行为：在 `main.sh` 菜单中按 `Ctrl+C` 会恢复终端并退出脚本，回到普通 SSH 终端；子脚本执行安装或卸载时按 `Ctrl+C` 只终止当前任务，主菜单显示中断提示并返回当前模块的上一级菜单。

## 开发约定

所有脚本以 POSIX `sh` 为目标，文件末尾记录精确到分钟的 `Last updated` 时间。测试脚本只在临时目录中生成，局部测试和完整测试结束后统一删除。
