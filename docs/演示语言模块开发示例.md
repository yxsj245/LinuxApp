# 演示语言模块开发示例

本文件是一个无副作用的语言模块开发示例。它不属于 `config/modules.list`，不会出现在 LinuxApp 的运行菜单中，也不会被离线模式当作必需脚本检查。

## 使用方式

复制下面的脚本内容到新的模块目录，例如：

```text
modules/language/example/module.sh
```

然后在 `config/modules.list` 中增加一行：

```text
language|example|modules/language/example/module.sh|示例语言
```

语言模块只支持：`install`、`uninstall`、`status`。语言环境不使用软件服务的启动、停止和更新动作。

以下动作是可选能力，实现后在 `capabilities` 中声明即可被框架自动接入菜单：

- `capabilities`：输出空格分隔的能力名，例如 `versions switch update`；
- `versions`：每行输出 `版本|current` 或 `版本|installed`，只读本地状态；
- `switch [版本]`：切换已安装版本；声明 `switch` 后菜单出现“切换版本”；
- `update`：联网获取最新版本并切换生效；声明 `update` 后菜单出现“更新”。

真实语言模块（Java、Node.js、Go、Rust）的实现与共享库 `lib/lang.sh` 用法可参考
`modules/language/*/module.sh` 与 `docs/语言模块使用说明.md`。

## 示例代码

```sh
#!/bin/sh

module_state_root=${LINUXAPP_STATE_DIR:-${XDG_CACHE_HOME:-${HOME:-.}/.cache}/linuxapp/state}
module_state_file="$module_state_root/language-example.state"
module_version='示例语言'

module_read_state() {
    if [ -r "$module_state_file" ]; then
        sed -n '1p' "$module_state_file"
    else
        printf '%s\n' 'not-installed'
    fi
}

module_status() {
    if [ "$(module_read_state)" = 'installed' ]; then
        printf '已安装|%s|示例语言环境已准备\n' "$module_version"
    else
        printf '未安装|-|尚未安装示例语言\n'
    fi
}

module_install() {
    mkdir -p "$module_state_root" 2>/dev/null || return 1
    printf '%s\n' 'installed' > "$module_state_file" || return 1
    printf '%s\n' '示例语言已经安装。'
}

module_uninstall() {
    rm -f "$module_state_file" 2>/dev/null || return 1
    printf '%s\n' '示例语言已卸载。'
}

trap 'printf "\\n%s\\n" "示例语言任务已被 Ctrl+C 中断。" >&2; exit 130' INT
case "${1:-status}" in
    capabilities) printf '%s\n' '' ;;
    install) module_install ;;
    uninstall) module_uninstall ;;
    status) module_status ;;
    start|stop) printf '%s\n' '语言模块不支持该动作。' >&2; exit 2 ;;
    *) printf '%s\n' '未知的语言动作。' >&2; exit 2 ;;
esac

```

## 开发注意事项

- 模块脚本必须使用 POSIX `sh`，不能依赖 Bash 专属语法。
- 状态输出使用 `状态|信息或版本|说明|可选敏感字段` 格式；第四列默认明文显示，框架 `--hide-secrets` 时会遮成 `******`。
- 需要“切换版本”或“更新”能力时，实现对应动作并在 `capabilities` 中声明。
- 真实语言环境模块应自行处理发行版、架构、权限和依赖差异。
- 完成模块后再把它登记到 `config/modules.list`，登记后离线模式会要求脚本存在。
