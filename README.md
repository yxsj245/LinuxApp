# LinuxApp

LinuxApp 是一个面向 Linux 的纯 POSIX `sh` 脚本集合，用于统一管理软件、语言环境和常用系统操作。

项目强调轻量、可迁移和可扩展：用户只需要运行 `main.sh`，即可进入交互式菜单；模块脚本按照统一生命周期接口工作，并支持在线加载、缓存、离线清单校验和用户级 SSH 登录钩子。

## 项目主页与开源地址

- 项目主页：将仓库部署到静态服务后访问根目录的 `index.html`
- GitHub：<https://github.com/yxsj245/LinuxApp>

主页先提供“一键使用”主入口，下面的“已有应用”区域当前留空。点击“复制命令”即可将主入口命令粘贴到 Linux 终端；命令中的入口地址会根据当前静态站点地址自动生成。

## 快速开始

```sh
cd LinuxApp
chmod +x main.sh
./main.sh
```

离线模式：

```sh
./main.sh -offline
```

SSH 登录钩子：

```sh
./main.sh --install-ssh-hook
./main.sh --remove-ssh-hook
```

## 当前结构

```text
LinuxApp/
├── index.html                       # 静态项目主页、应用目录与一键命令
├── main.sh                          # 运行入口
├── config/                          # 下载地址与模块清单
├── lib/                             # POSIX sh 公共库
├── modules/                         # 已登记的实际模块
├── docs/                            # 使用文档与模块开发示例
├── AGENTS.md                        # 项目开发规则
└── README.md                        # 项目说明
```

演示软件和演示语言只作为开发示例保存在 `docs/`，不会自动出现在运行菜单。`config/modules.list` 已登记 4 个语言模块，可直接在菜单中使用。

## 语言模块

`modules/language/` 下提供四个语言环境模块，安装源可选国内镜像或官方源：

| 语言 | 能力 |
| --- | --- |
| Java（Temurin JDK） | 安装、切换版本、更新（补丁 / 大版本）、修复环境、按版本卸载 |
| Node.js | 安装、切换版本、更新（补丁 / 大版本）、修复环境、按版本卸载 |
| Go | 安装、更新、修复环境、按版本卸载 |
| Rust | 安装、更新（rustup）、修复环境、按工具链卸载 |

多版本可以共存。卸载时会列出已安装的版本，输入编号只卸载该版本，输入 `a` 卸载全部版本；
卸载当前版本会自动切换到剩余版本中最新的一个，删除最后一个版本时清理安装目录与生态源配置。

安装后会自动完成环境接入：环境变量写入 shell 启动文件（登录 shell 与交互式非登录 shell 都覆盖），
并在 `/usr/local/bin`（普通用户为 `~/.local/bin`）建立命令入口（Java、Node.js、Go 为指向当前版本的
符号链接，Rust 为导出 `RUSTUP_HOME`、`CARGO_HOME` 的包装脚本），因此新开终端、`ssh 主机 '命令'`、
脚本等场景都能直接使用 `java`、`node`、`go`、`rustc` 等命令，切换版本后无需重新登录。
“修复环境”可在注入内容被误删或命令找不到时重建这些内容。

语言模块的安装位置、源对照表、版本切换与更新策略、自动化环境变量见 [语言模块使用说明](docs/语言模块使用说明.md)。

## 静态托管

网页不依赖构建工具或后端接口。部署时请保持 `index.html` 与 `main.sh` 的相对位置不变，例如使用 Nginx、GitHub Pages、对象存储静态网站或其他静态文件服务。

在线脚本默认从 `https://linuxapp.xiaozhuhouses.asia/` 加载。需要临时切换到其他镜像时，可通过 `LINUXAPP_BASE_URL` 环境变量覆盖默认地址。

网页已有应用和命令清单位于 `index.html` 内的 `apps` 数组。新增应用或命令后，请同步更新该数组。

## 兼容性

- 目标 Shell：POSIX `sh`
- 已验证：Ubuntu 环境下的 `dash` 与 Bash
- 静态网页：现代桌面和移动浏览器
- 网页复制命令：优先使用 Clipboard API，HTTP 或非安全上下文自动降级到传统复制方案
